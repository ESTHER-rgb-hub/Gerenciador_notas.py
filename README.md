# Gerenciador notas
# Sistema de Gerenciamento de Notas Acadêmicas

Este projeto implementa um sistema simples para gerenciar o desempenho acadêmico de estudantes.  
Ele permite:
- Armazenar dados de estudantes (nome e notas).
- Calcular médias individuais.
- Verificar aprovação com base em regras institucionais.
- Gerar relatórios organizados e claros para consulta.

## 🚀 Tecnologias
- Python 3.10 ou superior
- Biblioteca padrão `unittest` para testes

## 📂 Estrutura
- `src/` → Código principal do sistema
- `tests/` → Testes unitários
- `README.md` → Documentação
- `requirements.txt` → Dependências
